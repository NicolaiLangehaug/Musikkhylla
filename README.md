# Musikkhylla

Platesamlingen min som et rom: hylla, kassene og platespilleren, med alle platene.

- `index.html` – selve rommet
- `covers/` – omslagene, samlet i åtte ark
- `data/tilstand.json` – flyttinger, nye og fjernede plater, ønskelista (oppdateres fra rommet)
- `omslag/` – omslag til plater lagt inn i rommet

Endringer lagres hit fra rommet når en GitHub-nøkkel er lagt inn på enheten.
